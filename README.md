# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## About

This project practices basic HTML skills: boilerplate structure, headings, paragraphs, lists, links, and images.

## Skills Demonstrated

- HTML5 boilerplate and semantic structure
- Unordered and ordered lists
- Relative links between pages
- Embedding images
- Git workflow (add, commit, push)
